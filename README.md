GUI-приложение «Random Quote Generator» с использованием random, сохранением истории и Git.
# Random Quote Generator

**Автор:** [Арипшев Кантемир]

## Описание
Приложение на Python с графическим интерфейсом (Tkinter), которое позволяет получать случайные вдохновляющие цитаты. 

### Функции:
- Генерация случайной цитаты из базы данных.
- Сохранение всей сессии и прошлых запросов в файл `history.json`.
- Фильтрация истории по автору или категории (теме) в реальном времени.
- Автоматическая загрузка истории при запуске.

## Использование
1. Запустите файл: `python main.py`.
2. Нажмите **"Сгенерировать цитату"**.
3. Чтобы найти цитаты конкретного автора в истории, введите его имя в поле фильтра и нажмите **"Применить"**.

## Тестирование
- **Проверка JSON:** После генерации 2-3 цитат убедитесь, что в папке появился файл `history.json`.
- **Проверка фильтра:** Если в истории есть "Эйнштейн", введите "наука" в фильтр — в списке должны остаться только его цитаты.
